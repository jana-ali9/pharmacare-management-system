# PharmaCare – Pharmacy Management System

A full-stack pharmacy management system developed using PHP, MySQL, JavaScript, and Bootstrap.

##  Project Overview
PharmaCare is a web-based pharmacy management system designed to automate pharmacy operations including medicine management, customer orders, reporting, and user authentication.

##  Features
- Medicine inventory management
- Shopping cart and order system
- Dynamic invoice generation
- Admin dashboard
- Reports and order tracking
- User authentication (Login / Signup)
- Role-based access control (Admin & Users)
- Responsive UI design

##  Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP
